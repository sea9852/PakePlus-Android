# 打卡 · 纯离线移动端应用

零依赖、零构建的静态应用。所有数据只写入设备本地存储（WebView 的 localStorage），
**没有任何网络请求，断网、飞行模式下功能完全一致**。

---

## 一、怎么运行

**方式 1：直接打开（最省事）**

双击 `index.html`，用浏览器打开即可。桌面浏览器里会以 430px 宽的手机尺寸居中显示。

**方式 2：手机浏览器预览**

把这个文件夹放到局域网可访问的位置，或者用任意静态服务器：

```bash
# 项目根目录下任意选一种
npx serve .
python -m http.server 8080
```

手机访问 `http://<电脑IP>:8080`。

> 注意：直接双击 `index.html` 时，部分浏览器会限制 `file://` 下的 localStorage。
> 如果发现打卡后没有记录，请改用「方式 2」。打包进 APK 后不存在这个问题。

---

## 二、用 PakePlus 打包成 APK

PakePlus 支持「静态文件打包」，不需要安装 Android SDK，本地打包不需要 GitHub Token。

1. 打开 PakePlus → **新建项目**
2. 打包类型选择 **本地静态文件 / 打包本地网页**（**不要**选「网页 URL」，那是加载远程地址，会失去离线能力）
3. 目录指向本文件夹 `punch-card/`，入口是 `index.html`
4. 填写应用名称（如「打卡」）、包名（如 `com.yourname.punchcard`）、图标
5. 平台勾选 **Android**
6. 点击打包 / 发布，等待生成 APK 并安装

打包后的应用就是一个原生 WebView 外壳，所有 HTML/CSS/JS 都在安装包内，
运行时不需要联网，也不需要任何服务器。

## 四、数据模型

存储键：`punch.records.v1`，值为记录数组，按时间升序保存。

```js
{
  id:   "r1a2b3c",            // 唯一 id
  date: "2026-10-26",         // 本地日期，分组键
  t:    1761444060000,        // epoch 毫秒，精确打卡时刻
  note: "完成晨会纪要",        // 备注，空则为 null
  c:    1761444060000         // 写入时间
}
```

| 字段 | 说明 |
|---|---|
| `date` | 由手机本地时区算出的「天」，不是 UTC 日期。凌晨 0 点后打卡不会串到前一天。 |
| `t` | 展示与排序依据。当天记录按 `t` 升序即为「第 1 次、第 2 次…」。 |
| `note` | 备注，空白字符串统一规整为 `null`。 |

数据量参考：每天 3 次、连续 10 年约 1 万条，占用不到 1 MB，localStorage 完全够用。

> **提醒**：数据存在应用沙盒里，卸载应用会一并清除。如需长期留存，
> 建议后续再加一个「导出 JSON 备份」入口（`App.Store.exportJSON()` 已经准备好，
> 只差一个触发按钮）。

## 五、已实现的功能

- 首页绿色大圆按钮，点击弹出备注输入（可留空），保存点击那一刻的时间
- 一天可打卡多次；首页实时显示「今日已打卡 N 次」+ 最近 3 条记录
- 左滑平滑切到日历视图，再左滑进入全部记录，右滑返回，底部页码点提示
- 日历：月份大字标题、「今天」一键回到当月并选中今天、左右滑动翻月（带跟手阻尼与进出场动画）
- 日历格：非本月灰显、今天标绿、**打卡次数可视化**（1 次一个点、2 次两个点、3 次及以上一段绿色短条）
- 选中日期：白色圆角高亮块 + 数字加粗
- 下方卡片以时间轴样式竖排当天记录：`时间 → 圆点 → 备注`，多行自动对齐
- 无记录时显示空状态「暂无记录」；卡片下方显示当月统计，点击进入全部记录
- **全部记录页**：按月分组倒序，每行显示「日期 + 星期 + 全部时间点 + 次数」，多次打卡用绿色胶囊突出；点任意一行跳回日历并定位该日
- 长按任意一条记录可删除（带二次确认）
- 打卡成功有轻提示、按钮涟漪与震动反馈

## 六、交互细节

- **手势冲突**：只有在日历月网格区域内横向拖动才会翻月，其余区域的横向拖动翻页，
  纵向拖动交给原生滚动，三者通过轴向锁定互不干扰。
- **页面数量自适应**：`Pager` 从 DOM 读取页面数并按页数均分宽度，将来加页只需插入
  一个新的 `<section class="page">` 和对应 `<i>` 页码点，无需改动 CSS。
- **月份跳转是绝对定位**：`animateToMonth(year, month, dir)` 由参数决定目标月份，
  动画只负责视觉过渡；连点「今天」不会漂移（内部有动画 token 保护）。
- **时区安全**：日期键一律用 `getFullYear/getMonth/getDate` 计算，不使用 `toISOString()`，
  避免 UTC 偏移导致的跨日错误。
- **首屏不跳动**：月视图固定 42 格（6 行），切换月份时网格高度恒定。
- **次数标记实时同步**：打卡或删除后只更新受影响格子的标记，不整格重绘，避免闪烁。
